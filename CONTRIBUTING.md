# 🤝 Contributing

First of all, thank you for your interest in contributing to this project! ❤️

The goal of this repository is to make **Linear Algebra easier to understand through Python visualizations**. Every contribution, whether it's fixing a typo or adding a new visualization, is greatly appreciated.

---

## Ways You Can Help

You can contribute by:

- 🐛 Fixing bugs
- ✨ Improving visualizations
- 📖 Enhancing documentation
- 🎨 Improving animations
- ⚡ Optimizing code performance
- 💡 Suggesting new visualization ideas

---

## Before You Start

Please make sure to:

- Follow the existing project structure.
- Write clean and readable Python code.
- Follow PEP 8 style guidelines.
- Keep animations smooth and educational.
- Test your code before submitting.

---

## Project Structure

Each project should include:

```
Project/
│
├── README.md
├── requirements.txt
├── static_*.py
├── animated_*.py
└── preview.gif
```

---

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Test everything.
5. Commit your changes.
6. Open a Pull Request.

---

## Reporting Issues

Found a bug?

Please open an Issue and include:

- A clear description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

---

## Suggestions

Have an idea for a new visualization or improvement?

Feel free to open an Issue or start a discussion.

---

## Thank You ❤️

Every contribution helps make this repository a better learning resource for everyone.

Happy coding! 🚀
